**AudioBookShelf Streams**

See who is listening on your AudioBookShelf server, right from the Unraid Dashboard. Shows each user as *Listening*, *Paused* or *Connected*, with the book cover, title and author, a progress bar and the device in use. Includes a stop-session button and auto-refresh. Configure the server URL and an admin API token under Settings &rarr; Utilities &rarr; AudioBookShelf Streams.
